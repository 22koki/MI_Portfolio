# Faith.Dev Portfolio

A cinematic developer portfolio for **Faith Wahome** — Full-Stack Developer, Product Builder and Digital Marketer.

This is designed as a client-conversion website rather than a conventional résumé page. It presents software development, business systems, product thinking, automation and digital marketing in one visual portfolio.

Python, Django, Flask, JavaScript, React, Flutter, Dart, PostgreSQL, MySQL, REST APIs, Git/GitHub, HTML/CSS, PHP, Godot, M-PESA integrations and analytics tools.

## Run locally

This first version is static and has no build step.

```bash
git clone https://github.com/22koki/MI_Portfolio.git
cd MI_Portfolio
```

Open `index.html` directly or serve the directory using any static development server.
